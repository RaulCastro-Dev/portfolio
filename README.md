## 🛠️ Stack Tecnológico del Portfolio

Este proyecto está construido inicialmente con tecnologías web nativas, priorizando el rendimiento, la accesibilidad y un diseño adaptativo (*responsive*):
* **Estructura:** HTML5 semántico.
* **Estilos:** CSS3 Moderno (Variables CSS, Flexbox, Grid Layout, Diseño Adaptativo).
* **Interactividad:** JavaScript (Vanilla).
* **Control de versiones:** Git & GitHub.

---

## 📁 Estructura

```
portfolio/
├── index.html   # Contenido y estructura de la página
├── style.css    # Estilos (tema oscuro, diseño de dos columnas, responsive)
└── script.js    # Año del pie, foco de luz y resaltado del menú al hacer scroll
```

## ▶️ Ver en local

Es una web estática: basta con abrir `index.html` en el navegador, o servirla con cualquier servidor estático, por ejemplo:

```bash
python -m http.server 5173
```
